<h2>The Good Quest Foundation Donated Areas – Interactive Map </h2><br>
<h3>Overview</h3>

This webpage provides an interactive visualization of areas supported or donated by the NGO, displayed on a Leaflet-based map. Each location is enriched with geotagged photographs and relevant contextual information to improve transparency, awareness, and impact reporting.
Stay Updated on the good work TGQF are doing to support positive change. <br><br>
The platform is designed to help stakeholders, donors, volunteers, and the public easily explore where and how contributions have been utilized. Applying GIS to advance in the mission and create a just, sustainable, and peaceful world where everyone can thrive. This unique perspective on creating, managing, analyzing, and mapping all types of data empowering team to better communicate causes, understand communities, act on mission and measure impoacts.<br>


<h3>Features</h3>
<h4>🗺️ Interactive Leaflet Map</h4>
Displays donated areas using markers <br>
Supports zooming and panning for better exploration
Changing basemap according the need
<h4>📍 Geotagged Photos</h4>
Each donated location includes photos linked via GPS coordinates<br>
Visual proof of on-ground impact
<h4>🧾 Location Details</h4>
Area name and location<br>
LatLong of the location<br>
Time and date

<h3>Tech Stack</h3>
Frontend: HTML, CSS, JavaScript<br>
Backend: Python to generate point file as markers<br>
Mapping Library: Leaflet.js<br>
Map Tiles: OpenStreetMap, Topomap, <br>
Media: Geotagged images (PNG) <br>
Data Source: GeoJSON  <br>
